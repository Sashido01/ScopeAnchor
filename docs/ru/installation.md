# Установка

Устанавливать пакет и сторонние runtime-зависимости не нужно. Можно использовать нативный skill, необязательный CLI или оба компонента.

## Skill в проекте

Скопируйте полный каталог `.agents/skills/scope-anchor/` в `.agents/skills/` целевого репозитория. Сохраните `SKILL.md`, `agents/openai.yaml` и файлы `references/`. Если папка уже есть, сначала сравните содержимое и объедините изменения осознанно.

## Skill пользователя

Расположение пользовательских skills и их обнаружение зависят от среды Codex. Для воспроизводимой работы в конкретном репозитории предпочтительна проектная установка. Не меняйте глобальные настройки Codex только ради ScopeAnchor.

## CLI на Python

При необходимости установите Python 3.10 или новее штатным способом для вашей ОС. `pip install` не нужен.

### Windows PowerShell

```powershell
py -3 --version
py -3 src/scope_anchor.py --help
```

### Ubuntu

```bash
python3 --version
python3 src/scope_anchor.py --help
```

Пути с пробелами поддерживаются, если передать их одним аргументом в кавычках, например `--out "рабочая папка/TASK.md"`.
