# Начало работы

ScopeAnchor — прежде всего нативный Agent Skill для Codex. Необязательный CLI на Python помогает подготовить и проверить структуру контракта задачи, но не исполняет задачу.

## Использование skill

1. Скопируйте `.agents/skills/scope-anchor/` в каталог `.agents/skills/` целевого репозитория. Перед обновлением изучите уже существующую папку.
2. Откройте в Codex диалог для этого репозитория и явно попросите `$scope-anchor` выполнить многошаговую инженерную задачу.
3. Позвольте skill проверить запрос и изучить `AGENTS.md`, исходный код и тесты самого проекта до внесения изменений. Он выявляет повторы, противоречия, отсутствие критериев приёмки, неуказанные инструменты, лишний контекст и расширение объёма.
4. Проверьте объём задачи, критерии приёмки и итоговые подтверждения. Skill не отменяет инструкции пользователя и ограничения среды.

Обнаружение проектных skills зависит от среды Codex. Установка файлов не меняет глобальную конфигурацию, а CLI не проверяет обнаружение или активацию.

## Использование CLI

Для CLI нужен Python 3.10+. Выполните из корня репозитория:

```console
python src/scope_anchor.py new --out TASK.md --goal "Описать поведение импорта"
```

Заполните все значения `TODO`, затем выполните `check` и `compile`. См. [установку](installation.md) и [использование](usage.md).
