# Contributing

English is the canonical documentation language. The Russian translation is maintained in parallel; update both language versions in the same change.

## Before opening a change

- Keep the implementation Python 3.10+ standard library and native Agent Skills. Do not add network calls, third-party runtime dependencies, or services without a demonstrated need.
- Open an issue only for a concrete bug or scoped proposal. Do not include credentials, private task text, or personal project details.
- Keep changes focused and describe user-visible behavior, limitations, and verification evidence.

## Local checks

From the repository root, run:

```console
python -m unittest discover -s tests -v
python -m compileall -q src
python src/scope_anchor.py check examples/complete-task.md --json
python src/scope_anchor.py compile examples/complete-task.md
git diff --check
```

Windows PowerShell: use `py -3` if `python` does not select Python 3.10+. Ubuntu: use `python3`. GitHub Actions covers Windows and Ubuntu on Python 3.10 and 3.13; local checks do not prove hosted CI.

## Pull requests

Use a short, descriptive English commit subject. Include tests for behavior changes, update paired English/Russian documentation, and state any platform or runtime checks not performed. Never commit `.scope-anchor/`, `.env`, logs containing user content, generated bytecode, or secrets. Do not force-push to shared branches.
