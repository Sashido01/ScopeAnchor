# Участие в разработке

Канонический язык документации — английский. Русский перевод поддерживается параллельно: изменяйте обе языковые версии в одном изменении.

## Перед изменением

- Сохраняйте Python 3.10+ со стандартной библиотекой и нативные Agent Skills. Не добавляйте сетевые вызовы, сторонние runtime-зависимости или сервисы без доказанной необходимости.
- Открывайте Issue только для конкретной ошибки или ограниченного предложения. Не включайте учётные данные, приватный текст задач и сведения о личных проектах.
- Ограничивайте diff и описывайте пользовательское поведение, ограничения и подтверждения проверок.

## Локальные проверки

Из корня репозитория выполните:

```console
python -m unittest discover -s tests -v
python -m compileall -q src
python src/scope_anchor.py check examples/complete-task.md --json
python src/scope_anchor.py compile examples/complete-task.md
git diff --check
```

Windows PowerShell: если `python` выбирает несовместимую версию, используйте `py -3`. Ubuntu: используйте `python3`. GitHub Actions проверяет Windows и Ubuntu с Python 3.10 и 3.13; локальный запуск не доказывает результат CI на GitHub.

## Pull Request

Используйте короткое понятное сообщение коммита на английском. Добавляйте тесты для изменений поведения, обновляйте парные английские и русские документы и указывайте непроверенные платформы и среды. Не коммитьте `.scope-anchor/`, `.env`, логи с текстом пользователя, байткод и секреты. Не используйте force-push в общих ветках.
