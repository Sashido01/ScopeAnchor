# Политика безопасности

## Поддерживаемая версия

Исправления безопасности готовятся для последней версии ветки `main`. Отдельной ветки долгосрочной поддержки и гарантированных сроков обслуживания нет.

## Сообщить об уязвимости

Используйте [приватную форму GitHub vulnerability reporting](https://github.com/Sashido01/ScopeAnchor/security/advisories/new). Укажите затронутую версию или commit, возможное влияние и краткие шаги воспроизведения. Не передавайте реальные секреты и посторонние персональные данные. Не публикуйте детали эксплуатации в открытых Issues или Pull Requests.

Если GitHub сообщает, что приватная форма недоступна, не публикуйте детали эксплуатации. Проверьте страницу Security репозитория на наличие другого приватного канала; не предполагайте адрес электронной почты или срок ответа, которые нигде не опубликованы.

Сообщения рассматриваются по мере возможностей сопровождающего. Срок подтверждения или исправления не гарантируется. Приветствуется согласованное раскрытие.

## Границы

CLI — офлайн-помощник, а не граница безопасности. Он не исполняет текст задания, но перед передачей или компиляцией контракта пользователь должен сам проверить его содержимое. См. [руководство по безопасности и данным](docs/ru/troubleshooting.md#безопасность-и-данные).
