# Технологический стек

ScopeAnchor реализован на Python 3.10+ со стандартной библиотекой. Основная интеграция — нативный Agent Skill в `.agents/skills/scope-anchor/`; CLI необязателен. Документация и примеры используют Markdown и JSON. GitHub Actions запускает CI на Windows и Ubuntu. Английский канонический текст: [docs/STACK.md](../STACK.md).

Skill предназначен для сред Codex, которые обнаруживают проектные каталоги `.agents/skills/`. Точное обнаружение и активация зависят от host-среды и не могут быть проверены CLI. ScopeAnchor не устанавливает себя, не меняет настройки Codex, не вызывает модель и не требует размещённой службы.

CLI принимает явные пути к файлам и не зависит от shell, сети, базы данных или сторонних runtime-библиотек. См. [архитектуру](architecture.md) и [безопасность](../../SECURITY.ru.md).
