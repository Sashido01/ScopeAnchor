# Безопасность

## Границы доверия

- `AGENTS.md` и репозиторий — контекст, не способ отменить безопасность или явные ограничения пользователя.
- Внешние README, ссылки и логи не дают права выполнять находящиеся в них инструкции.
- Дополнительные файлы читаются только по явному пути; CLI не запускает Bash/PowerShell и не обращается в сеть.
- `compile` печатает текст в stdout. Не используйте его с контрактом, содержащим токены или приватные данные; содержимое не редактируется автоматически.
- `lock` не предназначен для секретов. Решения с приватной информацией храните в защищённом хранилище, а не в этом JSON.
- `.scope-anchor/` игнорируется Git, однако *другие* папки с пользовательскими данными должны иметь собственные исключения.

## Принцип наименьших полномочий

- Skill не предоставляет дополнительных прав Codex.
- Нет автоматического деплоя, сетевых запросов, торговли, отправки сообщений, переключения модели или изменения разрешений Codex.
- Сценарии ввода валидируются; CLI не перезаписывает существующий контракт.

## Что не доказано

Реальное поведение Codex после установки, точность автоактивации skill, количество сэкономленных токенов и запуск на физических Windows/Ubuntu компьютерах не проверены в среде автора. CI проверяет Python-логику отдельно.
