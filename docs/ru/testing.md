# Тестирование и проверка

Запускайте команды из [руководства по разработке](development.md) в корне репозитория. Текущий набор модульных тестов охватывает разбор контрактов, запуск CLI в отдельном процессе, дубликаты и повреждённый JSON, Unicode и полный цикл чтения/записи решений, явную замену значения, запрет символических ссылок там, где это поддерживается, и отказ от перезаписи файлов задач.

Матрица CI включает Windows и Ubuntu с Python 3.10 и 3.13. Только завершившийся GitHub Actions run подтверждает результат для commit в GitHub. Локальные проверки подтверждают только текущую среду. Ни те, ни другие сами по себе не доказывают автоматическое обнаружение skill или успешное выполнение задачи моделью.

Проверяйте относительные ссылки документации, manifest skill и его файлы, соответствие английских/русских примеров и статусов, а также отсутствие локальных данных и секретов в staged tree и доступной истории коммитов.
